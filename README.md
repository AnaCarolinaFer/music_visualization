# Seen Music - Floresta Sincronizada WebGL

Interactive 3D music visualization application that creates an animated forest responding to real-time audio input.

## Features
- 3D WebGL forest visualization with audio-reactive plants
- Real-time audio analysis (FFT, amplitude, beat detection)
- Multiple audio input methods (microphone, file upload, test tones)
- Interactive controls for sensitivity, dance intensity, and 3D depth

## Technologies
- p5.js v1.7.0 (with p5.sound)
- WebGL with custom GLSL shaders
- Web Audio API

## Usage
Open `webgl-forest-fixed.html` or `webgl-forest-fixed2.html` in a modern web browser.

## Controls
- Audio input selection (microphone/file/test tone)
- Adjustable sliders: Sensitivity, Dance Intensity, 3D Depth
- Press 'D' key for debug display
